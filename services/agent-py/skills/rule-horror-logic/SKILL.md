# 规则怪谈逻辑博弈规范（Rule Horror Logic Skill）

## 核心原则
1. **条文措辞必须精准冷硬**：规则文本应像日常管理告示或值班守则，却在某一条出现违背常识的冰冷限定（时间、颜色、人数、称呼）。
2. **逻辑自洽与隐蔽漏洞**：若存在“污染条文”或“相互矛盾规则”，必须通过前文细节或他人惨痛样本留下可推理的辨别依据，绝不事后强行圆场。
3. **角色理性求生**：主角通过低成本试探、交叉验证与利用条文字面空隙自保，绝不强行降智触犯明写死规。
4. **代价必有回响**：一旦触发禁忌，哪怕未立刻致命，也须在后续表现为理智值波动、感知污染或步步紧逼的清算倒计时。

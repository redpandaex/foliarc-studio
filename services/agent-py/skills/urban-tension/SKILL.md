# 都市现实与职场张力规范（Urban Tension Skill）

## 核心原则
1. **具体现实摩擦胜过宏大口号**：用会议室座位、合同补充条款、深夜未回的微信、账单数字与通勤疲惫承载真实压力。
2. **成年人的克制博弈**：职场与亲密关系的冲突往往包裹在礼貌、沉默与利益权衡之下，拒绝无脑咆哮和降智打脸桥段。
3. **对手亦是立体人**：反派或竞争对手必须有合理的业绩、生存或立场诉求，避免脸谱化工具人。
4. **情感递进有落点**：每一次关系升温或裂痕都须由具体行动与取舍触发，忌空洞抒情独白。

# 古风人物对话润色规范（Ancient Dialogue Skill）

## 核心原则
1. **话留三分，潜台词优先**：上位者说话克制留白，同辈交锋带机锋，下位者言辞谨慎。避免人物把心里话直白吐露出来。
2. **动作穿插打破“纯对话墙”**：每两到三轮对白之间穿插微动作（摩挲茶盏、垂眸看剑穗、抬指拂尘）映射真实情绪。
3. **半文半白，忌现代职场腔**：杜绝“逻辑、格局、执行力、情绪价值”等出戏现代词；也不要堆砌生僻文言造成阅读障碍。
4. **一人一腔调**：结合人物性格标签，让粗豪武夫、清冷剑修、老谋长老的句式长短和用词明显区分。

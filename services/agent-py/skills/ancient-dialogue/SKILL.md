# 古风人物对话润色规范（Ancient Dialogue Skill）

## 核心原则
1. **话留三分，潜台词优先**：上位者说话克制留白，同辈交锋带机锋，下位者言辞谨慎。避免人物把心里话直白吐露出来。
2. **严守礼法尊卑与避讳**：自称、尊称、谦称须与身份官职、宗族辈分严格对应，不出现现代职场或网络流行语。
3. **动作穿插打破“纯对话墙”**：每两到三轮对白之间穿插微动作（摩挲茶盏、垂眸看袖口、轻叩案几）映射真实情绪。
4. **半文半白，一人一腔调**：结合人物性格与出身，让粗豪武夫、清冷剑修、老谋世家子弟的句式长短和用词明显区分。

# 古典与历史世情行文规范（Classical Prose Skill）

## 核心原则
1. **白描为骨，节制留白**：以简洁准确的动静描写传神，少堆砌华丽形容词与长段心理剖析；喜怒藏于起坐行止、茶烟灯影之间。
2. **器物时令与礼法精准**：衣冠、车马、饮食、称谓、官制与时辰须符合时代肌理，杜绝现代概念词与出戏器物。
3. **彻底清除网文套话与翻译腔**：禁用“嘴角勾起一抹弧度”“眼神骤冷”“空气仿佛凝固”“破防”等句式。
4. **长短句交错与章回余韵**：叙事疏密有致，结尾不必强行爆炸反转，一盏残灯、一句淡语或一纸书信亦可余味悠长。

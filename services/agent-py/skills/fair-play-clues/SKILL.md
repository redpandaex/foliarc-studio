# 悬疑推理公平线索规范（Fair-Play Clues Skill）

## 核心原则
1. **公平埋点（藏木于林）**：决定破案的关键物证与时间点必须自然融入现场环境或日常闲谈，让细心读者同样能看见，严禁揭晓时凭空掏出新证据。
2. **客观事实与口供严格分离**：描写证人陈述时保留其主观视角与微表情停顿，区分“现场实拍事实”与“某人声称如此”。
3. **红鲱鱼须合乎人物动机**：误导性嫌疑人不能纯为凑数，其遮掩之事须符合自身真实秘密。
4. **节制推演，忌长篇说教**：将推理拆成“发现矛盾 → 现场验证 → 对质击穿”的动态过程，拒绝一口气念完千字结论。

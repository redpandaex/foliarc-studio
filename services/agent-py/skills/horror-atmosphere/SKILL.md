# 恐怖与灵异氛围营造规范（Horror Atmosphere Skill）

## 核心原则
1. **严禁直接播报情绪**：绝对禁止写“他感到无比恐惧”“令人毛骨悚然”“一阵寒意直窜天灵盖”。改为描写生理与感官细节（喉咙发干、指尖发僵、水声停在门外半步、灯丝嗡鸣变调）。
2. **日常的微米级错位**：最刺骨的诡异来自熟悉事物多出或少了一点——全家福里多出一只搭在肩上的手、廊灯亮着却没有影子、熟人说话的停顿像背诵录音。
3. **声音与空间的窒息感**：善用狭窄空间、视野遮挡、环境静音与突兀单点声响制造心理压迫。
4. **假安全与留白**：允许角色短暂以为危机已过，再用一个轻描淡写的反常细节拉回深渊；绝不过早科普鬼怪机制。

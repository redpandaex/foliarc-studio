# 科幻与末世硬逻辑规范（Sci-Fi Hard Logic Skill）

## 核心原则
1. **设定即边界，严禁万能名词糊弄**：严格尊重本书已确立的科技树与物理法则，绝不用“量子波动/纳米修复”充当无成本魔法。
2. **资源账目具象化**：电量、氧气、净水、滤芯寿命、义体过载度等硬指标必须融入叙事压力与行动代价。
3. **工业与环境质感**：通过金属冷凝水、气压表读数、电磁杂音、全息投影噪点等具体物理感官建立可信世界。
4. **技术压强下的人性切片**：让冷硬的技术/生存规则逼出人物的真实立场与阵营博弈。

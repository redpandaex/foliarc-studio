# 打斗场景描写规范（Combat Scene Skill）

## 核心原则
1. **以短句拉快节奏，以感官替代空洞形容**：少用“威力惊天动地、电光火石”等套话，多写兵器震颤、虎口裂血、气浪掀衣、呼吸灼痛与环境损毁。
2. **明确双方战力边界与代价**：严格核对人物当前境界/装备、伤势与能耗（先核实设定），绝不无视旧伤或无代价越阶碾压。
3. **三段式动作节拍**：
   - **起势试探**：交代空间站位、光线/环境与心理压迫。
   - **变招破局**：至少出现一次“预判落空 → 借势反制”的战术博弈，而非纯数值对轰。
   - **余波落点**：交代胜负代价（损耗、破损、新伤或遗留线索），顺势引出下一幕。

## 禁忌检查
- 禁止连续三句以上纯招式报菜名。
- 禁止忽略已持有的特定法器/装备特征。

# 高张力潜台词对话规范（Dialogue Subtext Skill）

## 核心原则
1. **表层谈闲事，底层谈生死/利益**：双方表面围绕茶水、天气或琐事客套，每一句都在试探对方的底牌与漏洞。
2. **用停顿、回避与转移话题替代直说**：一个问题不正面回答、反问一句无关细节、或突然放下杯子，往往比激烈争吵更有压迫感。
3. **严格遵守信息差（POV 边界）**：人物只能依据自己听到的原话与观察到的微表情做出推测，绝不允许隔空读心。
4. **每轮交锋必须改变局势权重**：对话结束时，至少有一方试探出了新情报、暴露了破绽，或被迫让渡了主动权。

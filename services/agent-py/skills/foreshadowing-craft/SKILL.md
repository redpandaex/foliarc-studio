# 伏笔埋设与回收规范（Foreshadowing Craft Skill）

## 核心原则
1. **冰山原则（藏于日常动作与物件）**：高明伏笔绝不靠旁白明说“他日后必会后悔”，而是藏在一个轻微反常细节里（如倒茶时护住左手腕、账本缺页却无撕痕）。
2. **严守保密边界**：未到启用引爆章时，严禁提前挑破幕后真相，只能通过表面线索与人物细微反应制造余韵。
3. **回收时的“情理之中，意料之外”**：回收伏笔时须精准呼应当年埋设的原文意象与物件流向，让读者自行拼合真相，避免长篇大论说教。

## 落笔检查
- 本章最多推进 1~3 条伏笔线，避免信息过载。
- 每次回收旧伏笔，须与埋设章节的时间线和原文锚点零矛盾。

# 悬疑伏笔埋设与回收规范（Foreshadowing Craft Skill）

## 核心原则
1. **先查后埋，防“写了就忘”**：动笔前优先调用 `list_open_foreshadowings` 检索当前未回收伏笔；若新埋关键线索，应调用 `update_foreshadowing` 登记追踪。
2. **冰山原则（隐藏在日常动作中）**：高明伏笔绝不靠旁白明说“他日后必会后悔”，而是藏在一个反常细节里（如对方倒茶时下意识护住左手腕、古籍缺了一页却无撕痕）。
3. **回收时的“情理之中，意料之外”**：回收伏笔时只需轻点旧物/旧话，让读者自己拼出真相，避免长篇大论“柯南式解说”。

## 落笔检查
- 本章最多推进 1~2 条主暗线，避免信息过载。
- 每次回收旧伏笔，须与埋设章节的时间线和物品流向严格吻合。

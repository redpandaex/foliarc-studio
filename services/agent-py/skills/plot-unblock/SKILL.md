# 卡文破局与章节节拍规范（Plot Unblock Skill）

## 破局四步法
1. **给主角制造“两难选择”**：好的推进不是“敌人更强”，而是“救人就会暴露身份，隐忍就会失去唯一机会”。
2. **引入外部倒计时或意外变数**：用突发事件（密信、时间窗口关闭、旧识撞破）打破当前静态僵局。
3. **盘活前文已有暗线**：优先从已埋未回收伏笔或旧人物关系中抽取破局钥匙，让全书因果咬合。
4. **章末必留“三选一钩子”**：信息钩子（揭露半句异常真相）、危机钩子（退路被断）或抉择钩子（主角跨出不可逆一步）。

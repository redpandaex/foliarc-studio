# 卡文破局与章节节拍规范（Plot Unblock Skill）

## 破局四步法
1. **给主角制造“两难选择”**：好的推进不是“敌人更强了”，而是“救人就会暴露身份，隐忍就会失去关键线索”。
2. **引入外部倒计时或意外访客**：用突发变故（密信、阵法异动、旧识现身）打断当前静态对话。
3. **利用已有未回收伏笔**：优先调用 `list_open_foreshadowings` 或 `search_worldbook`，把前文埋过的设定翻出来作为破局钥匙，让全书严丝合缝。
4. **章末必留“三选一钩子”**：
   - 信息钩子（揭露半句惊人真相）
   - 危机钩子（退路突然被切断）
   - 决定钩子（主角做出不可逆的关键抉择）
